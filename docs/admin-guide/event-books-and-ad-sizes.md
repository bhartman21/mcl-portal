# Event books and ad sizes

For: Ad Book Approvers, Department Admins, and National Admins.

> **Please note:** like ads, program books and ad sizes are saved only in the web browser on the computer you used. Shared saving is planned.

## Program books

A program book holds approved ads for one event, such as the Department convention.

### Make a new book

1. Open **Ad Book Studio**.
2. Under **Event Program Books**, press **New Event Book**.
3. Type the **Book Title**. Example: "2026 Fall Conference Program".
4. Type the **Event Name**. Example: "DoF Fall Conference".
5. Press **Create Book**.
6. You will see "Event book created."

### Open a book

1. Under **Event Program Books**, find the book.
2. Press **Open Book & Print Preview**.

### Place an approved ad in a book

1. Open the book.
2. Make sure the book is **Open**. (See "Book status" below.)
3. Under **Place Approved Ad**, pick an ad from the list.
4. Press **Add**.
5. The ad appears under **Placed Ads**.

Only approved ads can be placed. If none are waiting, you will see "No unplaced approved ads available. Approve submitted ads in the Approval Queue first."

### Change the order of ads

Under **Placed Ads**, use the buttons on each row:

- Up arrow (**Move up**)
- Down arrow (**Move down**)
- X (**Remove from book**)

These buttons only show while the book is **Open**.

### Book status

Under **Book Controls**, press one of:

- **Open** — ads can be added, moved, and removed.
- **Locked** — no ads can be added, moved, or removed.
- **Printed** — the same as Locked. Use it to show the book has been printed.

To make changes to a Locked or Printed book, press **Open** again.

### Print the book

1. Open the book.
2. Press **Print / Save PDF**.
3. Your computer's print window opens.
4. To make a PDF, choose "Save as PDF" (or similar) as the printer.

The preview shows Letter-size (8.5 × 11 inch) pages. Each page shows the book title and page number at the bottom.

## Ad sizes

### Open the ad sizes page

1. Open **Ad Book Studio**.
2. Press **Ad Sizes**.
3. The **Configurable Ad Sizes** page opens.

Sizes marked **Inferred** have measurements that the Department has not confirmed yet (Quarter Page and Business Card).

### Add a size

1. Under **Add Custom Size**, type a **Label**. Example: "Two-Thirds Page".
2. Type the **Width (in)** and **Height (in)** in inches.
3. Type **Slots / Page** — how many of these ads fit on one page.
4. Press **Add Size**.

### Turn a size off or on

- Press **Deactivate** to hide a size from the ad editor.
- Press **Activate** to show it again.

Members can only pick sizes that are active.
